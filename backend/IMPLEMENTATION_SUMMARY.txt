AUTHORIZATION MODEL
================================================================================

Host Privileges (caller_id):
- Invite participants to call
- Remove participants from call
- Promote any participant to host
- Mute/unmute any participant
- Update quality for any participant
- View all call state and participants

Participant Privileges:
- Update own media state
- Mute/unmute own audio/video
- Update own video quality
- Leave the call
- View call state and other participants

Viewer Privileges:
- View-only access
- Cannot transmit media
- Cannot perform any actions
