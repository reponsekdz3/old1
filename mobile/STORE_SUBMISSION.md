## 🚀 Submission Process

### iOS (App Store)

1. **Prepare Build**
```bash
npm run build:ios
```

2. **Upload to App Store Connect**
```bash
npm run submit:ios
```

3. **Complete App Store Connect**
   - Add screenshots
   - Fill app information
   - Set pricing
   - Submit for review

4. **Review Process**
   - Typical: 1-3 days
   - Check status in App Store Connect

5. **Release**
   - Automatic release after approval
   - Or manual release on your schedule

---

### Android (Play Store)

1. **Prepare Build**
```bash
npm run build:android-aab
```

2. **Upload to Play Console**
```bash
npm run submit:android
```
   Or manually upload AAB in Play Console

3. **Complete Store Listing**
   - Add screenshots
   - Fill app information
   - Complete content rating
   - Set pricing & distribution

4. **Review Process**
   - Typical: Few hours to 1 day
   - Check status in Play Console

5. **Release**
   - Staged rollout (recommended)
   - Start with 5% → 10% → 50% → 100%

## 🔄 Post-Launch

### Monitoring
- Monitor crash reports (Sentry, Firebase Crashlytics)
- Track user reviews and ratings
- Analyze user acquisition metrics
- Monitor server load and API usage

### Updates
- Bug fixes: Patch version (2.0.1)
- New features: Minor version (2.1.0)
- Major changes: Major version (3.0.0)

### OTA Updates (Over-The-Air)
```bash
eas update --branch production --message "Bug fixes"
```
- No app store review required
- JavaScript/asset changes only
- Users get updates automatically

### Full Rebuild Required For:
- Native code changes
- Dependency updates
- Permission changes
- App store information changes
